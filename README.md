# Smart Inventory Tracker
Smart Inventory Tracker is a simple desktop application designed to help users manage and monitor their inventory efficiently. The application uses JavaFX for the user interface and SQLite as the local database.
This project was developed as a final practical assignment for the Advanced Programming course at Universitas Muhammadiyah Malang.

## ✨ Key Features
- **Dashboard**: Displays summarized inventory data.
- **Inventory List**: Add and manage product entries.
- **Expiry Alert**: Shows products that are about to expire and allows deletion.
- **Restock Recommendation**: Displays low-stock products and enables stock updates.

## ⚙️ Technologies Used
- **Programming Language**: Java
- **GUI Framework**: JavaFX
- **Database**: SQLite
- **Dependency Manager**: Maven

## 🛠️ Installation
### System Requirements
- Java JDK 11 or higher
- Maven installed.
- SQLite 

### Installation Steps
1. Clone repository:
   ```bash
   git clone <url-repository>
2. Masuk ke directory project:
   ```bash
   cd Smart-Inventory-Tracker
3. Compile dan Run
   ```bash
   mvn clean javafx:run
   
## 🗂️ Project Structure
- **src/main/java**: Main source code.
- **src/main/resources**: Resource files such as assets and FXML.
- **src/test/java**: File testing.
  
## 🚀 How to Use
1. Run the application using your IDE or terminal:
   ```bash
   mvn clean javafx:run
2. Add new products through the Inventory List menu.
3. Check for products nearing expiration under the Expiry Alerts menu.
4. Remove expired products via the Expiry Alerts menu.
5. Monitor low-stock items in the Restock Recommendation menu.
6. Add stock as needed through the same menu.
